## Scientific Plot Studio · SPS

**在 Mac 上读取 Origin 工程，制作可移植的科研图表。**

SPS 读取受支持的 Origin `.opj` / `.opju` 文件，将数据和图形样式保存在可重新编辑的 `.spsfig` 工程里。图件可以随 PowerPoint 演示文稿携带，也可以导出 SVG / PDF 到 Illustrator 排版。

欢迎科研同学试用、报告问题，一起改进代码、文档和示例。
